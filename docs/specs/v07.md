# NBodiesGravity v0.7.0 Implementation Plan

## 1. Release Objective

**v0.7.0 is the scientific diagnostics, orbital analysis, and physical visualization release.**

Following the numerical robustness and validation infrastructure established in v0.6.0, v0.7.0 exposes the simulation's physical and dynamical behavior to the user. The application moves from visual animation to an analytical laboratory where orbital mechanics, conservation laws, and dynamical statistics can be observed, plotted, and exported in real time.

---

## 2. Baseline & Prerequisites

v0.7.0 builds directly upon the merged `v0.6.0` release (`main` / `master` commit `ff55329`):
- Explicit `TimeStepConfig` with safe substep budgeting (`ComputationalBudgetExceededError`).
- Numerical failure protection (`NumericalIntegrityError`).
- Plummer-softened potential energy, kinetic energy, linear momentum, angular momentum, and center of mass in `nbodiesgravity.engine.diagnostics`.
- Deterministic canonical benchmarks A–F.
- Verified Velocity Verlet integrator and full test suite.

### Important Design Rule (Roadmap Section 7)
> **Diagnostics must consume the same simulation state used by the physics engine.** They must not reconstruct physical quantities from rendered coordinates.

## 4. Workstream 1 — Orbital Elements Engine

### 4.1 Theory & Mathematical Model

For a body with relative position $\mathbf{r} = \mathbf{r}_{\rm body} - \mathbf{r}_{\rm primary}$ (AU) and relative velocity $\mathbf{v} = \mathbf{v}_{\rm body} - \mathbf{v}_{\rm primary}$ (AU/day) around a primary of mass $M$, with standard gravitational parameter:
$$\mu = G(M + m)$$
in units of $\text{AU}^3\,\text{day}^{-2}$.

1. **Specific Relative Angular Momentum**:
   $$\mathbf{h} = \mathbf{r} \times \mathbf{v}, \quad h = |\mathbf{h}|$$

2. **Node Vector**:
   $$\mathbf{n} = \hat{\mathbf{z}} \times \mathbf{h} = (-h_y, h_x, 0), \quad n = |\mathbf{n}|$$

3. **Eccentricity Vector & Scalar Eccentricity**:
   $$\mathbf{e} = \frac{1}{\mu} \left( (\mathbf{v} \cdot \mathbf{v} - \frac{\mu}{r})\mathbf{r} - (\mathbf{r} \cdot \mathbf{v})\mathbf{v} \right), \quad e = |\mathbf{e}|$$

4. **Specific Orbital Energy & Semi-Major Axis**:
   $$\varepsilon = \frac{v^2}{2} - \frac{\mu}{r}$$
   $$a = -\frac{\mu}{2\varepsilon} \quad (\text{for } e \neq 1)$$

5. **Inclination**:
   $$i = \arccos\left(\frac{h_z}{h}\right) \in [0, \pi]$$

6. **Longitude of Ascending Node**:
   $$\Omega = \begin{cases} \arccos\left(\frac{n_x}{n}\right) & \text{if } n_y \ge 0 \\ 2\pi - \arccos\left(\frac{n_x}{n}\right) & \text{if } n_y < 0 \end{cases} \quad (\text{defined when } i \neq 0)$$

7. **Argument of Periapsis**:
   $$\omega = \begin{cases} \arccos\left(\frac{\mathbf{n} \cdot \mathbf{e}}{n e}\right) & \text{if } e_z \ge 0 \\ 2\pi - \arccos\left(\frac{\mathbf{n} \cdot \mathbf{e}}{n e}\right) & \text{if } e_z < 0 \end{cases} \quad (\text{for non-circular, inclined orbits})$$

8. **True Anomaly**:
   $$\nu = \begin{cases} \arccos\left(\frac{\mathbf{e} \cdot \mathbf{r}}{e r}\right) & \text{if } \mathbf{r} \cdot \mathbf{v} \ge 0 \\ 2\pi - \arccos\left(\frac{\mathbf{e} \cdot \mathbf{r}}{e r}\right) & \text{if } \mathbf{r} \cdot \mathbf{v} < 0 \end{cases}$$

9. **Periapsis, Apoapsis & Period**:
   $$r_p = a(1 - e)$$
   $$r_a = a(1 + e) \quad (\text{for } e < 1)$$
   $$T = 2\pi \sqrt{\frac{a^3}{\mu}} \quad (\text{for } a > 0, e < 1)$$

### 4.2 Module & API

Location: `nbodiesgravity/engine/orbital_elements.py`

Classes / Functions:
- `@dataclass(frozen=True) class OrbitalElements`: Holds $a, e, i, \Omega, \omega, \nu, r_p, r_a, T, \text{period\_days}, \text{specific\_energy}, \mathbf{h}, \mathbf{e}$.
- `compute_orbital_elements(r, v, mu) -> OrbitalElements`: Robust against edge cases (circular $e \to 0$, equatorial $i \to 0$, parabolic/hyperbolic $e \ge 1$).
- `compute_elements_for_body(body, primary_body) -> OrbitalElements`: Convenience helper extracting relative vectors and $\mu$.
- `find_dominant_primary(body, all_bodies) -> CelestialBody | None`: Automatically identifies the gravitational parent body (largest $G M_j / r_{ij}^2$).

## 5. Workstream 2 — Diagnostics History & Substep Accounting

### 5.1 Substep Accounting (Roadmap & v0.6 Item 10)
Expose exact integration statistics from `SolarSystem.step()`:
- `last_substeps_count`: Actual substeps performed during the most recent step.
- `last_adaptive_dt`: Selected adaptive timestep size.
- `cumulative_substeps`: Total substeps since simulation launch.

### 5.2 Diagnostics History Buffer
Location: `nbodiesgravity/engine/diagnostics.py`

Class: `class DiagnosticsHistoryBuffer`:
- Thread-safe fixed-capacity ring buffer (e.g. 2,000 points) tracking:
  - `times`: Simulation days elapsed.
  - `energy_rel_drift`: $\Delta E / E_0$.
  - `momentum_norm_drift`: $\Delta P / \text{momentum\_scale}$.
  - `angular_momentum_rel_drift`: $\Delta L / L_0$.
  - `kinetic_energy`, `potential_energy`, `total_energy`.
  - `substeps_per_step`.
- Methods:
  - `append(elapsed_days, report, substeps)`
  - `clear()`
  - `get_arrays() -> dict[str, np.ndarray]`

## 6. Workstream 3 — Scientific Diagnostics UI & Live Plotting

### 6.1 Requirements & Architecture
Location: `nbodiesgravity/ui/diagnostics_dialog.py` (or dock widget in `nbodiesgravity/ui/`)
- Non-modal interactive window/dock, toggleable via `View -> Scientific Diagnostics` menu or toolbar button.
- Sub-tabs / Sections:
  1. **Conservation Overview**:
     - Real-time tabular metrics: Total Energy, Kinetic, Potential, Linear Momentum, Angular Momentum, Center of Mass.
     - Drift meters / badges (color-coded green/amber/red based on tolerances).
     - Substep throughput and integration efficiency statistics.
  2. **Orbital Elements Inspector**:
     - Dropdown to select any active body.
     - Dropdown to select primary reference center (default: Auto-dominant or Camera focal body).
     - Clean display of $a$ (AU & km), $e$, $i$ (deg), $r_p$, $r_a$, $T$ (days & years).
  3. **Live Conservation Plots**:
     - Embedded Matplotlib canvas (`FigureCanvasQTAgg` via `matplotlib.backends.backend_qtagg`).
     - Subplots for:
       - Relative Energy Drift $\Delta E / E_0$ vs. Time.
       - Linear & Angular Momentum Drift vs. Time.
       - Substep count / adaptive dt vs. Time.
     - "Clear History" button and time-window selector (e.g. Last 100 days, Last 1 year, All).

## 8. Workstream 5 — Adaptive vs. Fixed Convergence Tooling (Deferred Item 9)

Location: `scripts/compare_convergence.py`
- Benchmarks Canonical Systems (e.g. Earth-Sun and Eccentric Kepler) across fixed timesteps vs. adaptive timestepping.
- Produces quantitative comparisons:
  - Total substeps taken.
  - Wall-clock compute time.
  - Final relative energy drift.
  - Maximum coordinate error compared to high-resolution reference.
